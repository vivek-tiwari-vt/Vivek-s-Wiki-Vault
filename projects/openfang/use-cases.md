# OpenFang use cases

OpenFang is positioned around autonomous agent work rather than interactive-only AI chat.

## Common use cases

- scheduled recurring research and monitoring workflows
- lead discovery and enrichment
- social/media operational support
- workflow pipelines with branching and event-driven triggers
- enterprise messaging integration via channel adapters

## Practical workflow examples

- Competitive monitoring: background hands discover and score targets, with alerting on important shifts.
- Content operations: scheduled content posting with approval gates.
- Research synthesis: multi-source collection and structured summarization.

## Evidence quality

These use cases are grounded in project-authored docs and capability claims; independent validation is recommended before production procurement.
