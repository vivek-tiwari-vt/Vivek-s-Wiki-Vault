# OpenFang

## Summary

OpenFang is a Rust-based open-source agent platform positioned as an "Agent
Operating System" for running long-lived autonomous workflows across channels
such as Telegram, Discord, and Slack.

## What It Is

OpenFang is a public GitHub project from RightNow-AI that combines agent
runtime, CLI, dashboard, connectors, and workflow automation into one platform
instead of acting like a thin chatbot wrapper.

## What It Does

- Runs autonomous agents and scheduled workflows.
- Connects agents to messaging channels and external tools.
- Ships as a Rust workspace with CLI, runtime, API surface, and dashboard
  pieces.
- Provides install paths for a single binary, GitHub-based installation, and
  hosted docs at `openfang.sh`.

## What It's Used For

- Long-running AI assistants
- Scheduled tasks and automations
- Multi-channel agent operations
- Self-hosted or developer-managed agent platforms
