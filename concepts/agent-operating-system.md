# Agent Operating System

An Agent Operating System (AOS) treats agents as persistent, policy-governed runtime entities with scheduling, state, channels, and governance rules.

## Distinguishing traits

- Persistent execution over transient chat interactions.
- Workflow and trigger orchestration.
- Integration layers for tools, channels, memory, and policy enforcement.

## Examples

- OpenFang is one implemented example.

Claims and comparisons should be validated across vendors, because terminology can vary.
